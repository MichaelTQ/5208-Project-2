# 可并入 A 报告的方法文字

本项目从 data.gov.sg 下载 2017–2024 年全站点五分钟累计降雨数据，并保留各年度 CSV、来源元信息和本地文件 SHA-256。所有全量解析、清洗、时间连续性和覆盖率计算均采用 Apache Spark 3.5.8，固定新加坡时区。原始时间及数值字符串保留；雨量转换为 Decimal(20,9)，避免先舍入或浮点误差改变累计和阈值判断。

时间规范化只处理整五分钟网格和恰好提前一秒的记录：后者向前调整一秒，原始时间和调整量可追溯。按站点与规范时间检验唯一键，兼容重复确定性保留一个代表；同键雨量或有效位置发生冲突则整组隔离。无效记录按原因隔离，不插值或补零。固定极端雨量筛查阈值仅生成复核标记，不作为删除规则。

各站点跨年度相邻观测之间的缺失槽位由时间差精确计算。日/月/年覆盖率采用 SGT 日历网格分母，并另外报告首次至末次有效观测之间的 observed-span 覆盖率。首次之前和末次之后的状态保持未知，不据此推断设备投运或停运。日历覆盖率的日期归属按时间戳定义，与读数累计区间跨午夜的雨量归属分开解释。

官方现有说明确认五分钟更新及可能缺测、事后修订，但本次查阅未明确历史时间戳代表区间起点或终点。研究暂以区间终点解释，并在接口字段中保存假设状态。更新字段不视作已确认的实时首次可用性。本数据质量验收因此支持明确假设下的历史实验，不能单独证明实时部署效果。

验收包括原始文件不变、正式唯一键、时间网格、非负精确雨量、记录与雨量去向守恒、覆盖率分母、缺口与 span 缺失槽位逐站一致、真实交接样例一致，以及跨年、闰年、缺测和冲突人工边界案例。实际结果见 `artifacts/stage2/STAGE_2_CHECK_REPORT.md`。
