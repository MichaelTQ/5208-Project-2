# Stage 5：A 的完整报告材料

范围：原 A5 工作包。B 负责最终报告/PDF 整合；本阶段交付可直接合并的英文 Markdown 正文、中文合并说明、六组图注、表格和可追溯证据。Lecture 5/6 不需要提供。报告模板和篇幅未指定，不虚构限制。

1. 核对 Stage 1–4 的已验收证据及原始/正式数据规模；登记本轮报告输入摘要。
2. 从已验证的小型表提取年度结果、覆盖与缺口、清洗账本、硬件/软件及真实生产耗时；耗时逐项说明，不冒充从下载到模型的总时间。
3. 补充“站点差异是否稳定”：只用已经验证的全站共同日历支持表，逐年计算并列名次、名次范围、年度首位及两两 Spearman 秩相关。限定为五个月共同支持的描述，不用它拟合趋势或挑选模型站点。
4. 编写完整英文报告六部分：来源与数据概况、计算环境、清洗质量、跨年结果、站点差异、局限与 AI 使用。精确值由表/JSON 提取；图注注明分母与支持范围。
5. 提供 B 的合并说明：正文/图/表的对应关系、压缩篇幅建议、不可删除的限定条件、应由 B/C 补充的模型章节与真实人工审核声明。
6. 独立重算报告引用的年度值、账本、排名/相关与图表输入；检查正文图片/文件链接、引用、输入/输出摘要，生成 Stage 5 检查报告。正式数据和既有 Stage 3 图表不修改。

输出：docs/REPORT_A_FULL.md、REPORT_A_MERGE_GUIDE.md；artifacts/stage5/ 下的图注、事实、站点稳定性表、证据及验收报告。docs/REPORT_SECTION_A.md 保留为 Stage 3 短版，完整合并稿以 REPORT_A_FULL.md 为准。
